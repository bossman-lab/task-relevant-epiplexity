# Paper Drafts

- `task_relevant_epiplexity_en.md` is the English workshop/arXiv-style draft.
- `main.tex` and `references.bib` are the LaTeX manuscript source.
- `main.pdf` is the compiled LaTeX output.
- `figures/*.pdf` are paper-ready figures generated from experiment outputs.
- `build.ps1` compiles `main.tex` and auto-detects the user MiKTeX install path.
- `validate_manuscript.py` checks citation keys and figure paths without a TeX
  installation.
- `../task_relevant_epiplexity_paper_zh.md` is the Chinese working draft with
  more explanatory prose.

The English draft is the current main article. The Chinese draft is useful for
discussion and ideation.
